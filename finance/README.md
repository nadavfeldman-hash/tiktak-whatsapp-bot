# finance — מצב העסק מכל מקום

סקריפטים שרצים בלי המחשב של נדב. נועדו לסשן ענן של Claude Code, כדי שאפשר יהיה
לשאול "איפה אני עומד" מהנייד.

## הרצה

```bash
node finance/status.js          # החודש הנוכחי
node finance/status.js 2026-08  # חודש ספציפי
```

## מה זה מחזיר

- **הכנסות** — מה שנגבה בפועל החודש מארבוקס (SUCCESS בלבד), כמה משלמים
- **צפי לחודש מלא** — סכום המחיר של כל המנויים הפעילים עם חיובים פתוחים
- **כשלונות גבייה** — כמה נכשלו, ומי לא שילם כלום (אלה שבאמת צריך להתקשר אליהם)
- **הוצאות** — כל מסמך שנקלט במורנינג החודש, מקובץ לקטגוריות, עם מע"מ תשומות
- **שעות מאמנים** — משמרות רצופות מארבוקס כולל מה שעוד מתוכנן, כפול התעריף
- **שורה תחתונה** — מע"מ עסקאות מול תשומות, והחזר ההלוואה

## משתני סביבה נדרשים

| משתנה | מאיפה |
|---|---|
| `ARBOX_API_KEY` | ארבוקס → הגדרות → API |
| `MORNING_KEY_ID` | מורנינג → הגדרות → API |
| `MORNING_SECRET` | מורנינג → הגדרות → API |

בסשן ענן מוסיפים אותם כ-Secrets. מקומית הם נקראים מ-`.env` (לא נכנס ל-git).

## דברים שצריך לדעת

**שעות מאמנים** מחושבות כמשמרות רצופות ולא כשיעורים בודדים. במכון מתחיל אימון כל
10 דקות, ולכן ספירה לפי שיעורים מנפחת את השעות פי כמה. שיעורים שמתחילים בתוך 15
דקות זה מזה נחשבים למשמרת אחת.

**התעריפים קבועים בקוד** (`RATE` ב-`status.js`): שירה 100, לירן 100, חן 120,
דניאל 80. אם תעריף משתנה — לעדכן שם.

**החזר ההלוואה** (3,000 ₪) יוצא ישירות מהבנק ואין לו חשבונית, לכן מורנינג לא רואה
אותו והוא נספר ידנית כקבוע.

**מים כלולים בשכר הדירה** מקאר סנטר — אין ספק מים נפרד, וזה תקין.

**הצפי אינו תחזית.** הוא סכום המחירים של המנויים הפעילים — התקרה אם כולם יחויבו
בהצלחה. באוגוסט הצפי היה כ-56.7 אלף ונכנסו 55,577.
